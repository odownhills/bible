# Arabic text of the Quran

The text the Quran translation is made from: the standard written text (Uthmani script) in the Hafs
reading, 114 surahs and 6,236 verses.

- One file per surah, `<NNN>.txt`. Each line is a verse number, a tab, and the verse.
- Line `0` is the unnumbered opening line that stands at the head of every surah except Surah 9. In
  Surah 1 that line is verse 1.
- Taken unchanged from the npm package `quran-json` 3.1.2 (https://www.npmjs.com/package/quran-json,
  Creative Commons Attribution-ShareAlike 4.0), which takes its text from The Noble Qur'an Encyclopedia
  (https://quranenc.com).
- Never edit these files. If a verse here differs from the standard text, report it instead.
